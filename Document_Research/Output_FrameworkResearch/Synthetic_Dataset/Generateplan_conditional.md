# การสังเคราะห์ข้อมูลผังอาคาร (GeneratePlan Conditional Summary)

จากการตรวจสอบโค้ด `generate_layout.py` ร่วมกับ `config_housegan.json` และการวิเคราะห์ Metadata ของผังที่ถูกสร้างขึ้นจริงในโฟลเดอร์ `Geo_scenario` ทั้งหมด พบว่ามีข้อมูลสำคัญที่ต้องแบ่งแยกออกจากกันระหว่าง **"เงื่อนไขความซับซ้อนที่กำหนดตอนสั่งรัน (Target Complexity)"** และ **"ความซับซ้อนของผังที่เกิดขึ้นจริง (Actual Complexity)"** ดังนี้ครับ:

---

## 1. เงื่อนไขที่ใช้สั่งรัน (Target Parameters)
จากการอ่านฟิลด์ `params` ใน `metadata.json` ของทั้ง 610 ผัง พบว่าในขั้นตอนสั่งสร้างผ่านระบบ (เช่น config_housegan.json) **ไม่ได้มีการสั่งสร้างด้วยพารามิเตอร์ระดับ Small (3-5 Rooms)** เลย โดยมีสถิติการสั่งรันดังนี้:

| ลำดับ | ระดับความซับซ้อนที่ระบุในพารามิเตอร์ (Target Complexity) | โหมดขนาดห้อง (Room Area Mode) | จำนวนผังที่สร้าง (Layouts) |
|---|---|---|---|
| 1 | Medium (5-8 Rooms) | Default (unknown/default)* | 110 ผัง |
| 2 | Medium (5-8 Rooms) | Big | 100 ผัง |
| 3 | Large (8-15 Rooms) | Default (unknown/default)* | 100 ผัง |
| 4 | Large (8-15 Rooms) | Big | 100 ผัง |
| 5 | XL (15-20 Rooms) | Default (unknown/default)* | 100 ผัง |
| 6 | XXL (20-30 Rooms) | Default (unknown/default)* | 100 ผัง |
| **รวม** | | | **610 ผัง** |

*หมายเหตุ: โหมด `unknown` เกิดจากการรัน Script ในชุดแรกๆ ก่อนที่จะมีการอัปเดตฟีเจอร์ `room_area_mode` ลงใน metadata.json*

---

## 2. ความซับซ้อนที่เกิดขึ้นจริง (Actual Complexity)
เมื่อทำการนับจำนวนห้องจริงที่ถูกสร้างขึ้นและบันทึกอยู่ในไฟล์ JSON (ฟิลด์ `room_count` ใน `metadata.json`) พบว่า **มีผังขนาดเล็ก (Small 3-5 Rooms) เกิดขึ้นจริงถึง 142 ผัง!** โดยสรุปจำนวนผังจริงตามช่วงของห้องได้ดังนี้ครับ:

| ช่วงจำนวนห้องจริง | ระดับความซับซ้อนจริง (Actual Complexity) | จำนวนผังจริงที่พบใน Dataset |
|---|---|---|
| **3 - 5 ห้อง** | **Small** | **142 ผัง** |
| **6 - 8 ห้อง** | **Medium** | **152 ผัง** |
| **9 - 15 ห้อง** | **Large** | **182 ผัง** |
| **16 - 20 ห้อง** | **XL** | **73 ผัง** |
| **21 - 30 ห้อง** | **XXL** | **61 ผัง** |
| **รวมทั้งหมด** | | **610 ผัง** |

## 3. ทำไมถึงเกิด "ผังเล็ก (Small)" ทั้งที่ไม่ได้สั่งรัน? (Technical Deep Dive)
สาเหตุเกิดจากลอจิกในโค้ด [generate_layout.py](file:///Ubuntu/home/johnnie/programming/AI_Pedsim/AI_Pedsim/AI_GenerateImage/AI_Train/Generate_HouseGAN/generate_layout.py#L65-L87) ซึ่งใช้การวางตำแหน่งห้องแบบสุ่มและตรวจสอบการซ้อนทับกัน (Room Overlap/Collision Detection):
- อัลกอริทึมจะพยายามวางห้องต่อๆ กันให้ได้ครบตามจำนวนเป้าหมายที่สุ่มได้จากช่วงพารามิเตอร์ (เช่น หากสุ่มได้ 8 ห้องในระดับ Medium)
- ในแต่ละห้องที่จะวาง โค้ดจะสุ่มพิกัดและลองวางดูไม่เกิน **100 ครั้ง (Trials)** 
- หากรอบสุ่มนั้นชนกับห้องอื่นจนเต็มพื้นที่และไม่สามารถวางห้องถัดไปได้หลังจากครบ 100 ครั้ง โค้ดจะ**ข้าม (Skip)** ห้องนั้นไปทันทีและจบการสร้างผังด้วยจำนวนห้องที่วางได้สำเร็จ
- ผลลัพธ์คือ **ผังส่วนใหญ่จึงมีจำนวนห้องจริงน้อยกว่าช่วงพารามิเตอร์ที่ตั้งเป้าไว้** ตัวอย่างเช่น พารามิเตอร์ Medium (5-8 ห้อง) อาจวางห้องสำเร็จเพียง 3 หรือ 4 ห้องเท่านั้น ทำให้กลายเป็น "ผังเล็ก (Small)" ในทางปฏิบัติครับ

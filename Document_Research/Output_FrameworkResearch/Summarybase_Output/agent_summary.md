## 5. Discussion (ส่วนอภิปรายผล)
ผลการศึกษาในงานวิจัยนี้แสดงให้เห็นอย่างชัดเจนว่าการประยุกต์ใช้ AI Surrogate model สามารถทำนายเวลาในการเดินทาง (Travel time) ของผู้ใช้งานในพื้นที่สถาปัตยกรรมได้อย่างมีประสิทธิภาพ โดยเมื่อเปรียบเทียบระหว่างโมเดล Multi-Layer Perceptron (MLP) และ Graph Neural Network (GNN) พบว่า MLP ให้ผลลัพธ์ที่มีความแม่นยำสูงกว่าอย่างมีนัยสำคัญ (มีค่า Error ต่ำกว่า GNN ประมาณครึ่งหนึ่ง) ปรากฏการณ์นี้อธิบายได้จากการที่ MLP มีความสามารถในการเรียนรู้ความสัมพันธ์ระหว่างตัวแปรเชิงตัวเลขที่สกัดมาในรูปแบบ Feature-based ได้รวดเร็วและตรงไปตรงมาสำหรับงาน Regression อย่างไรก็ตาม แม้ GNN จะมีค่าความคลาดเคลื่อนที่สูงกว่า แต่มันแสดงให้เห็นถึงศักยภาพที่โดดเด่นในการจับความสัมพันธ์เชิงพื้นที่ (Spatial connectivity) และโครงสร้างของเส้นทางการเดิน (Movement-path relationships) ซึ่งเป็นสิ่งที่ระบบ Feature-based ทั่วไปไม่สามารถรับรู้ได้

ความท้าทายหลักที่ทำให้ GNN ยังทำผลงานได้ไม่เทียบเท่า MLP อาจเกิดจากการออกแบบ Graph representation ที่ยังไม่สามารถสะท้อนความซับซ้อนของพฤติกรรมมนุษย์ (เช่น มุมมองการมองเห็น หรือผลกระทบจากความหนาแน่นแบบพลวัต) ได้ครบถ้วน หากในอนาคตมีการปรับปรุง Graph node และ edge features ให้ครอบคลุมปัจจัยเชิงพลศาสตร์เหล่านี้ GNN อาจเป็นกุญแจสำคัญที่ทำให้โมเดลสามารถเข้าใจและทำนายแปลนอาคารที่ไม่เคยเห็นมาก่อน (Generalizability) ได้อย่างแม่นยำ การเลือกใช้โมเดลจึงขึ้นอยู่กับเป้าหมาย หากต้องการความแม่นยำและรวดเร็วสูงสุดจากข้อมูลจำเพาะ MLP ถือเป็นทางเลือกที่เหมาะสม แต่หากต้องการสร้างโมเดลที่เข้าใจบริบททางสถาปัตยกรรมอย่างแท้จริง การพัฒนา GNN ต่อไปคือสิ่งที่ท้าทายและคุ้มค่า

## 6. Conclusion (บทสรุป)
งานวิจัยนี้นำเสนอความสำเร็จในการพัฒนาระบบ AI Surrogate model เพื่อใช้ประเมินเวลาสัญจร (Pedestrian travel time) ในพื้นที่สถาปัตยกรรม แทนที่การใช้ Physics-based simulation แบบดั้งเดิมอย่าง Social Force Model ที่มักกินทรัพยากรการคำนวณสูงและใช้เวลานาน โมเดลที่พัฒนาขึ้น—โดยเฉพาะสถาปัตยกรรม MLP—สามารถทำนายเวลาได้ด้วยความแม่นยำสูง ผ่านการเรียนรู้จากฐานข้อมูลสังเคราะห์ (Synthetic dataset) จำนวน 3,400 สถานการณ์ บน 600 รูปแบบแปลน 

ผลลัพธ์จากงานวิจัยนี้ชี้ให้เห็นว่าเทคโนโลยี AI สามารถยกระดับเป็นเครื่องมือช่วยตัดสินใจ (Decision-support tool) ที่มีประสิทธิภาพสำหรับสถาปนิก โดยเฉพาะในขั้นตอน Early-stage design ซึ่งจำเป็นต้องมีการประเมินทางเลือกเชิงพื้นที่อย่างรวดเร็วและวนซ้ำหลายรอบ การเปลี่ยนผ่านจากการรัน Simulation เต็มรูปแบบมาเป็น Data-driven prediction เปิดโอกาสให้ผู้ออกแบบประเมินประสิทธิภาพทางสถาปัตยกรรมได้แทบจะ Real-time ส่งผลให้เกิดการออกแบบพื้นที่ที่มีความปลอดภัยและจัดการสัญจรได้ดียิ่งขึ้น แม้การศึกษานี้จะจำกัดอยู่ที่เส้นทางการเดินแบบ Single-destination แต่ก็ถือเป็นการวางรากฐานที่มั่นคงสำหรับการพัฒนาโมเดลจำลองพฤติกรรมฝูงชนในระดับสเกลและเงื่อนไขที่ซับซ้อนต่อไป

## 7. Limitations and Future Research (ข้อจำกัดและงานวิจัยในอนาคต)
**ข้อจำกัด (Limitations):**
1. **ลักษณะข้อมูลสังเคราะห์ (Synthetic Bias):** ข้อมูลทั้ง 3,400 scenarios สร้างมาจาก JuPedSim (Physics-based) ซึ่งโมเดล AI ของเราเรียนรู้พฤติกรรมในอุดมคติตามคณิตศาสตร์ อาจไม่ครอบคลุมความผันผวนของพฤติกรรมมนุษย์จริงๆ โดยเฉพาะในสถานการณ์ตื่นตระหนก (Panic) หรือสิ่งแวดล้อมที่เปลี่ยนแปลงได้ (Dynamic obstacles)
2. **ขอบเขตการสัญจร (Single-destination constraint):** Dataset ปัจจุบันมุ่งเน้นทดสอบเพียงสถานการณ์เดียวคือมุ่งหน้าไปยังจุดหมายเดียวกัน ทำให้ยังไม่ได้ทดสอบประสิทธิภาพกรณีการจราจรแบบสวนทาง (Bi-directional) หรือผู้คนมีความต้องการหลายจุดหมาย (Multi-destination)
3. **การประยุกต์ใช้กับอาคารขนาดใหญ่:** ชุดข้อมูลจำกัดที่ 600 layouts อาจเกิดข้อจำกัด (Overfitting) เมื่อนำไปใช้ทำนายแปลนที่มีความซับซ้อนสเกลเมืองใหญ่ เช่น สนามบิน หรือศูนย์การค้า

**งานวิจัยในอนาคต (Future Research):**
1. การขยายขอบเขต Dataset ให้ครอบคลุมความหนาแน่นสูง, ผู้คนเคลื่อนที่แบบ Multi-destination และเพิ่มสิ่งกีดขวาง
2. การนำข้อมูลจากการสังเกตในพื้นที่จริง (Real-world observations) หรือ VR Experiments มาผสานผ่าน Transfer Learning 
3. การยกระดับ Graph Representation สำหรับ GNN ให้ผนวกปัจจัยทางสายตา (Isovist) เข้าไปเป็น Feature ของแต่ละ Node

## 8. Scope การทดลอง (Experiment Scope)
- **ตัวแปรต้น (Independent Variables):** 
  - รูปแบบของแปลนพื้นที่ (Floor plan configurations - 600 รูปแบบ)
  - ระยะทางในการเคลื่อนที่ (Travel distances)
  - จำนวนผู้ใช้งานในพื้นที่ (Number of occupants)
- **ตัวแปรตาม (Dependent Variables):** 
  - เวลาที่ใช้ในการเดินทาง (Travel time) จากจุดเริ่มต้นถึงจุดหมาย
- **ข้อมูลที่ใช้ในการศึกษา (Data Scope):** 
  - ข้อมูลสังเคราะห์ (Synthetic data) สร้างจากการจำลองโดย JuPedSim 
  - ประกอบด้วย 3,400 สถานการณ์จำลอง ภายใต้ขอบเขตการเคลื่อนที่มุ่งไปสู่จุดหมายเดียว (Single-destination movement task)
- **โมเดลที่ใช้ประเมินผล (AI Surrogate Models Scope):**
  - Multi-Layer Perceptron (MLP) ประเมินผ่าน Feature-based regression
  - Graph Neural Network (GNN) ประเมินผ่าน Graph structure/Spatial representation
- **เกณฑ์การวัดประสิทธิภาพ (Evaluation Metrics):**
  - ค่าความคลาดเคลื่อน MAE, RMSE, MSE และการกระจายตัวด้วย Parity plots

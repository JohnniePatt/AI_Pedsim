# คำอธิบายฟังก์ชันสูญเสีย (Loss Functions) ใน Pix2Pix

ในการพัฒนาโมเดล Pix2Pix สำหรับสร้างภาพแผนที่ความหนาแน่น (Density Heatmap) นั้น เราใช้การผสมผสานของหลายฟังก์ชันสูญเสีย (Loss Functions) เพื่อให้ได้ผลลัพธ์ที่ทั้งมีความเร็วสูงและความแม่นยำทางสถิติ

## 1. L1 Loss (ความคลาดเคลื่อนสมบูรณ์เฉลี่ย - MAE)
L1 Loss คือการหาค่าเฉลี่ยของส่วนต่างระหว่างพิกเซลที่ AI สร้างขึ้นกับพิกเซลจริงจากข้อมูลต้นฉบับ

$$L_{L1}(G) = E_{x,y,z} [ \| y - G(x,z) \|_1 ]$$

*   **บทบาท:** บังคับให้ Generator (ตัวสร้างภาพ) วาดภาพให้มีค่าสี (Pixel Intensity) ตรงกับภาพต้นฉบับมากที่สุด
*   **ความสำคัญ:** ช่วยให้จุดกระจายตัวของคนใน Heatmap อยู่ในพิกเซลที่ถูกต้องตามแผนผังห้อง

## 2. MSE Loss (ความคลาดเคลื่อนกำลังสองเฉลี่ย)
MSE Loss คือการหาค่าเฉลี่ยของกำลังสองของส่วนต่างระหว่างภาพที่สร้างขึ้นเทียบกับภาพจริง

$$L_{MSE}(G) = E_{x,y,z} [ (y - G(x,z))^2 ]$$

*   **บทบาท:** ลงโทษความผิดพลาดที่มีขนาดใหญ่ (Large Errors) อย่างรุนแรง
*   **ความสำคัญ:** ช่วยในการควบคุมไม่ให้ค่าความหนาแน่นในจุดใดจุดหนึ่ง "โดด" หรือเพี้ยนไปจากความจริงมากเกินไป ช่วยเสริมความแม่นยำในจุดที่มีความหนาแน่นสูง

## 3. Adversarial Loss (GAN Loss)
เป็นคะแนนที่เกิดจากการแข่งขันกันระหว่างตัวสร้างภาพ (Generator - $G$) และตัวจับผิดภาพ (Discriminator - $D$)

$$L_{cGAN}(G, D) = E_{x,y} [\log D(x, y)] + E_{x,z} [\log(1 - D(x, G(x, z)))]$$

*   **เป้าหมายของ Generator:** พยายามทำให้ค่า Loss นี้ต่ำที่สุด (เพื่อให้ Discriminator แยกไม่ออกว่าภาพไหนคือภาพที่ AI วาด)
*   **บทบาท:** สร้างความ "เนียน" และความสมเหตุสมผลของภาพ ทำให้ภาพไม่เบลอเหมือนการใช้เพียงแค่ L1 Loss อย่างเดียว

## 4. Total Generator Loss (ค่าสูญเสียรวม)
ฟังก์ชันรวมที่ใช้ในการฝึกฝน Generator คือการนำค่าจาก GAN Loss มารวมกับ L1 Loss โดยให้น้ำหนักกับ L1 สูงกว่าเพื่อความแม่นยำ

$$L_{Total} = L_{GAN} + \lambda \cdot L_{L1}$$

*   **$\lambda$ (Lambda):** โดยปกติจะกำหนดไว้ที่ 100
*   **เหตุผล:** การให้น้ำหนัก L1 สูง ช่วยให้มั่นใจว่าโครงสร้างของห้องและตำแหน่งของฝูงชนใน Heatmap ไม่ผิดเพี้ยนไปจากอินพุตที่ระบุไว้ในแผนภาพห้อง

## 5. Discriminator Loss (ค่าสูญเสียของตัวจับผิด)
ทำหน้าที่ระบุความสามารถของตัวจับผิดในการแยกแยะระหว่างภาพ "จริง" (Ground Truth) และภาพ "ปลอม" (จาก AI)

*   **Real Loss:** เปรียบเทียบคู่ภาพจริงกับค่า 1 (จริง)
*   **Fake Loss:** เปรียบเทียบคู่ภาพปลอมกับค่า 0 (ปลอม)
*   **Total D Loss:** คือค่าเฉลี่ยของ (Real Loss + Fake Loss)

## 6. สรุปสั้นๆ: ค่าแบบไหนคือ "ดี"?

ในการอ่านผลลัพธ์จากไฟล์ `log_loss/training_history.csv` หรือจาก Terminal ให้ใช้หลักเกณฑ์นี้ครับ:

| ค่าที่บันทึก (Metric) | ทิศทางที่ต้องการ | ความหมาย |
| :--- | :--- | :--- |
| **L1 Loss (MAE)** | **ยิ่งน้อย ยิ่งดี** 📉 | ความผิดพลาดของแต่ละพิกเซลน้อยลงเรื่อยๆ |
| **MSE Loss** | **ยิ่งน้อย ยิ่งดี** 📉 | กำจัดความผิดพลาดใหญ่ๆ ได้ดีขึ้น (ภาพนิ่งและแม่น) |
| **G (Generator) Loss** | **ยิ่งน้อย ยิ่งดี** 📉 | AI วาดภาพได้เก่งขึ้นจนเริ่มแยกไม่ออกว่าจริงหรือปลอม |
| **D (Discriminator) Loss** | **พยายามอยู่ที่ประมาณ 0.5** ⚖️ | เป็นสมดุลที่เหมาะสม (D แยกจริง/ปลอมได้ยากขึ้น) |
| **Val L1 Loss** | **ยิ่งน้อย ยิ่งดี** 📉 | **(สำคัญที่สุด)** บอกว่า AI เอาไปใช้กับงานจริงได้ดีแค่ไหน |

> [!TIP]
> **ทำไมดูที่ Val L1 Loss เป็นหลัก?**
> เพราะคือค่าความแม่นยำที่สุดที่ใช้ข้อมูลใหม่ (Validation Set) หากค่านี้ต่ำ แสดงว่าโมเดลใช้งานได้จริง ไม่ใช่แค่ท่องจำข้อมูลเดิมครับ!

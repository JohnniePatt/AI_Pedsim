# AI_GenerateImage

This workspace is for AI methods that generate pedestrian trajectory lines.

- `AI_Train/` contains method code and training/testing configs.
- `AI_Result/` contains model outputs, checkpoints, knowledge indexes, and evaluations.
- `Streamlit_ui/` is the dashboard for training, testing, and viewing trajectory AI results.

Path convention:

- `AI_Result` is local to this module: `AI_GenerateImage/AI_Result`.
- Shared project data remains at the repository root: `../Dataset/Data_Traj_Table`, `../Geo_scenario`, `../Tool_utility`, and `../Formater`.
